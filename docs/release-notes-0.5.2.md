# Muses 0.5.2

This update improves playback reliability. Songs that need a renewed connection can recover more smoothly, seeking near the end of a song continues to the next track, and the queue stays aligned with the song that plays.

Muses is available for macOS 14 or later. Download the signed, notarized app from the [latest release](https://github.com/xiaotwu/Muses-Polyhymnia/releases/latest) and drag it into Applications. Your existing library stays in place.

The remaining device and long-running checks are recorded in [Remaining validation](https://github.com/xiaotwu/Muses-Polyhymnia/blob/main/docs/remaining-validation-0.5.1.md).
