# Installation

1. Download the latest Muses DMG from [Releases](https://github.com/xiaotwu/Muses-Polyhymnia/releases/latest).
2. Open the DMG and drag **Muses** into **Applications**.
3. Open Muses from Applications. The app is signed and notarized for macOS.

Muses requires macOS 14 or later. Your library remains available when you replace an earlier version of the app.

Start with Home, explore music, or import a playlist. You can connect an account in **Settings → Account** for your subscriptions and a more personal Home. Muses asks before using an optional browser session for Home.

If macOS asks for access to a browser session, follow the explanation shown in the app. You can continue listening without enabling it.
