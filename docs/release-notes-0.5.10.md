# Muses 0.5.10

The product wordmark and installer now share a champagne-gold identity.

- About displays **Muses · Polyhymnia** in Island Moments. The font is bundled for offline use and follows the interface text-size setting.
- The DMG opens with a warm-white background, champagne-gold wordmark, directional arrow, and fixed native drag-to-Applications layout. System file labels remain visible; extra instruction text is omitted.
- Existing library data, account connections, playback behavior, main-window Search, and the settings order introduced in 0.5.9 are preserved.

Requires macOS 14 or later on Apple Silicon (arm64). ZIP and DMG downloads are Developer ID signed, notarized, and stapled.

Validation: 758 tests in 105 suites passed on the 0.5.9 source baseline with the branding changes. Actual About and Finder installer windows were inspected during implementation.
