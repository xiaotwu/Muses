# Muses 0.5.1 后续验收与已知边界

2026-09-25。此文档单独记录首版发布时尚无充分实机证据的项目。它们不是已经通过的验收，也不代表已知功能故障。

| 项目 | 当前状态 | 后续验收方式 |
| --- | --- | --- |
| macOS 14 | 本轮仅在 macOS 27 安装和运行 | 在 macOS 14 的干净用户环境安装公证 DMG，验证启动、导入、播放、设置和升级 |
| 外接音频与实体媒体键 | 本机只有内建扬声器，未取得外接设备结果 | 接入有线或蓝牙输出，切换设备，试听连续播放，并核对实体播放/暂停、上下首 |
| 60 Hz 与 120 Hz 显示 | 已有短时滚动样本，但没有两种刷新率对照 | 同一资料库和场景下重复滚动与 Now Playing 操作，记录帧间隔及明显卡顿 |
| 两小时混合运行 | 仅完成较短的播放与性能采样 | 连续混合播放、切歌、视频覆盖层、睡眠唤醒、窗口切换，核对内存、音频和媒体卡片 |
| 个性化 Home 分页 | 已验证实际登录会话、账号匹配和首屏缓存；没有取得真实 continuation token | 在出现下一页入口的真实账号会话中加载下一页，并核对断网、失效和恢复 |
| 更完整的辅助功能 | 评论窗关闭按钮的英文、中文 VoiceOver 朗读已由用户确认 | 补查全局键盘导航、其他关键按钮朗读、高对比度、降低透明度、降低动态效果 |
| 冷缓存与性能热点 | 已有热缓存短时 CPU/RSS 和显示间隔样本 | 对照冷启动、冷滚动、更新耗时与主线程热点；不要把已有短时样本当成长时承诺 |
| 评论回复后续页 | 实际评论与回复读取通过，目标视频没有返回可点的后续页入口 | 遇到真实分页时实点验证；评论保持只读 |

首版发布接受上述验证范围。若用户报告可复现问题，优先记录系统版本、设备、操作步骤与可见结果，再开展有针对性的修复。
