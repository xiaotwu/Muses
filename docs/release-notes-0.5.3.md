# Muses 0.5.3

This update keeps Muses silent when its volume is set to 0%, including when a song changes. Songs added to a playlist now appear immediately, and playlist song actions work on the intended song.

Muses is available for macOS 14 or later. Download the signed, notarized app from the [latest release](https://github.com/xiaotwu/Muses-Polyhymnia/releases/latest) and drag it into Applications. Your existing library stays in place.

The remaining device and interface checks are recorded in [Remaining validation](https://github.com/xiaotwu/Muses-Polyhymnia/blob/main/docs/remaining-validation-0.5.1.md).
