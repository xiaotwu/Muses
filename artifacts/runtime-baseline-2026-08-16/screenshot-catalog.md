## Named capture blockers

- Album grid hover/selection and Album Detail: no albums or album relationships existed in the runtime library.
- Artist grid/detail: no artists existed.
- Playlist overview/detail/create/add/reorder: no playlists existed, and the empty “Playlists” heading was not selectable.
- True playing PlayerBar / artwork-rich Now Playing / live lyrics / live spectrum / rotating vinyl: starting the available YouTube track twice left the process and MediaRemote activity alive but removed the only Muses window. No screenshot from that state was accepted.
- Pointer hover: the available desktop automation exposed click, drag, scroll, and keyboard actions but no pointer-move-only action.
- Native context menu screenshot: the menu semantics were inspected through accessibility (`Play`, `Play Next`, `Add to Queue`, `Like`, `Edit Info`), but the saved OS capture showed the wrong background and was rejected.
