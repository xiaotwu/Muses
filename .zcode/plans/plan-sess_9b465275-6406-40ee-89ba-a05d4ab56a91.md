# Phase 10: Capsule PlayerBar + Full Icon Integration + Pure B&W Theme

## Overview
Three UI refinements requested by the user:
1. **Capsule playback component** — Transform the flat full-width PlayerBar into a floating, independent long capsule (rounded corners, margins, shadow)
2. **Full icon/logo integration** — Fix AboutView which still uses a gradient+"M" placeholder instead of the real `logo.png`
3. **Pure black/white theme** — All accent colors (magenta/cyan/green) become white (dark mode) / black (light mode)

---

## Task A: Capsule PlayerBar

**Files:** `Features/PlayerBar.swift`, `App/RootView.swift`

### PlayerBar.swift changes:
- Add `.clipShape(RoundedRectangle(cornerRadius: 20, style: .continuous))` to the outer HStack — creates the capsule shape
- Add `.shadow(color: .black.opacity(0.3), radius: 12, x: 0, y: 4)` for floating depth
- Keep `.background(.ultraThinMaterial)` (glass material on the capsule)
- Remove the invisible hairline overlay (no longer needed with capsule shape)
- Keep height at 72pt (slightly reduced from 76 for sleeker capsule proportions)
- Keep all existing controls (artwork, title/artist, prev/play/next, seek slider, like/repeat/shuffle/volume/queue)

### RootView.swift changes:
- Change the `.overlay(alignment: .bottom)` to add padding around PlayerBar so it floats:
  ```swift
  .overlay(alignment: .bottom) {
      PlayerBar(...)
          .padding(.horizontal, 12)
          .padding(.bottom, 12)
  }
  ```
- Add `.safeAreaInset(edge: .bottom)` or `.padding(.bottom, 88)` to the NavigationSplitView detail content so content scrolls above the floating capsule (bar height 72 + margins 12+12 = 96pt clearance)

## Task B: Full Logo/Icon Integration

- Replace the hardcoded `RoundedRectangle` + `LinearGradient(magenta→cyan)` + `Text("M")` placeholder with the real `logo.png` loaded from bundle

  ```swift
  if let url = Bundle.main.url(forResource: "logo", withExtension: "png"),
  ```

## Task C: Pure Black/White Theme (White Accent)

**Files:** `App/RootView.swift` (BrandColors), `Features/NowPlaying/MetalSpectrumView.swift`

### BrandColors changes (RootView.swift lines 166-177):
All three accent colors become white (dark) / black (light):

| Color | Dark (current → new) | Light (current → new) |
|-------|----------------------|----------------------|
| `magenta` | rgb(0.94, 0.56, 0.94) → **rgb(1, 1, 1)** white | rgb(0.82, 0.40, 0.82) → **rgb(0, 0, 0)** black |
| `cyan` | rgb(0.09, 0.66, 0.94) → **rgb(1, 1, 1)** white | rgb(0.05, 0.55, 0.85) → **rgb(0, 0, 0)** black |
| `green` | rgb(0.09, 0.66, 0.09) → **rgb(1, 1, 1)** white | rgb(0.06, 0.58, 0.22) → **rgb(0, 0, 0)** black |

This cascades automatically to all 75 usages across 22+ files (43 magenta + 22 cyan + 10 green) since every consumer references `BrandColors.*`.

### MetalSpectrumView.swift shader update:
Update the hardcoded Metal shader float values (lines 137, 142):
- Upper bars gradient: `magenta→cyan` → `white→white` (solid white with slight opacity gradient for depth: `float4(1.0, 1.0, 1.0, 1.0)` at bottom to `float4(0.7, 0.7, 0.7, 1.0)` at top)
- Lower mirror: `float4(0.94, 0.56, 0.94, 0.3)` → `float4(1.0, 1.0, 1.0, 0.3)` (white at 30%)

### Auto-updated (no manual changes needed):
- Canvas `SpectrumView.swift` — uses `BrandColors.magenta`/`BrandColors.cyan` → auto-updates
- Logo gradient fallbacks in SidebarView/SettingsSheet — `BrandColors.magenta`/`cyan` → white→white (solid), but real logo loads first anyway
- All button tints, active states, slider tints, badges — auto-cascade

### Kept as-is:
- `textPrimary` (light grey on dark / near-black on light) — stays, it's part of the B/W spectrum
- `textSecondary` (grey) — stays, provides hierarchy within B/W
- `surface` (near-black card bg) — stays, provides depth within B/W
- `scrim` (black overlay) — stays
- `hairline` (transparent) — stays
- `.red` for error text in YouTubeImportsView — semantic convention, kept
- Dynamic artwork gradients in HomeView/AlbumDetailView/NowPlayingView — content-derived colors, not theme colors, stay as-is
