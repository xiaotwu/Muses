# Phase 15: Apple Music-style Now Playing (expanded view) redesign

Reference = **Apple Music macOS** Now Playing (user-confirmed). Layout = **two-column** (artwork + controls left, time-synced lyrics right) with a compact **Up Next** list; the previous screenshots were lost so this is inferred from Apple Music and the two confirmed layout decisions.

Scope is the **expanded Now Playing overlay only** (`Features/NowPlaying/NowPlayingView.swift` + subviews). The compact `PlayerBar` is done (Phase 14) and not touched. Constraints preserved: personal use / non-App-Store / YT ToS / pure B&W theme (magenta=cyan=white in dark).

---

## Current state (what exists)
- `NowPlayingView` is an `.overlay` in `RootView` (opacity transition, `showNowPlaying`), `@Binding isPresented`. **Keep** this presentation — it works and avoids modal lifecycle changes.
- Layout today: top bar (chevron / "NOW PLAYING" / volume / play) → centered `CoverArtModeView`|`VinylModeView` (480pt, `artworkHash` only) → bottom panel: `SpectrumView` + title/artist/album/quality badge + scrubber + `WaveformView` + `LyricsView`.
- `LyricsView` already does **real time-synced karaoke** (LRCLIB/Musixmatch/local `.lrc`, auto-scroll, current line magenta+bold). **Reuse + restyle**, don't rewrite.
- `SpectrumView`/`MetalSpectrumView` (64 mirrored bars) and `WaveformView` (static overview + drag-seek) already work.
- **Gaps**: artwork region + background gradient only use `artworkHash` (local) — YouTube tracks fall back to placeholder; no Up Next inside Now Playing; no queue entry point from Now Playing.

## Task 1 — Two-column layout restructure (`NowPlayingView.swift`)
- Replace the single centered `centerContent` + `bottomPanel` with an `HStack(alignment: .top)` of `leftColumn` + `Divider`-less gap + `rightColumn`, inside the existing gradient `ZStack` (keep `extractGradient`, space-bar, `.onAppear`/`onChange(track.id)`).
- **Responsive**: wrap in `GeometryReader`; if `width >= 960` use two columns, else fall back to a vertical stack (art top → controls → lyrics → up next) so narrow windows still work.
- Keep the existing `topBar` (chevron.down dismiss / "NOW PLAYING" / volume). Add a **lyrics toggle** button (quote.bubble) that hides the right column, and a small **mode switcher** (cover/vinyl) — both in the top bar, Apple-Music-corner style. `NowPlayingMode` enum stays `cover`/`vinyl` (no new case).
- Add `var onShowQueue: () -> Void = {}` to `NowPlayingView`; wire in `RootView` to `showQueue = true`. Used by Task 3's "full queue" button.
- Build helper `artworkImage(for track: TrackSnapshot?) -> NSImage?` (local cache path → `NSImage(contentsOf:)`; else YouTube thumbnail `https://i.ytimg.com/vi/<id>/hqdefault.jpg` via `URLSession`/`NSImage(contentsOf: URL)`). Single source of truth used by the artwork region (Task 2) and `extractGradient` (Task 4).

## Task 2 — Left column: artwork + metadata + Apple Music transport + scrubber + spectrum
- **Artwork**: reuse `CoverArtModeView`/`VinylModeView` but extend them to accept the resolved `NSImage?` (or a small `ArtworkSource` enum: `.cached(NSImage)` / `.youtube(URL)` / `.placeholder`) instead of only `artworkHash`. Keep 480pt / cornerRadius 12 / shadow. Apply YouTube thumbnail via `AsyncImage` for the `.youtube` case.
- **Metadata** under art: title (title2 semibold), artist (subheadline), album (caption), and the existing `qualityBadge` (keep). Centered within the left column.
- **Transport** (Apple Music order, centered HStack with generous spacing): `shuffle` → `backward.fill` → `play.fill`/`pause.fill` (title2, magenta emphasis) → `forward.fill` → `repeat`/`repeat.1`. Shuffle/repeat tinted magenta when active, `textSecondary` otherwise. Reuse existing `playback.queue.toggleShuffle` / `setRepeat` cycle logic (same as the PlayerBar overflow menu).
- **Scrubber**: elapsed `Text` + `Slider` (magenta tint, existing `seeking`/`seekValue` drag logic) + remaining `Text`, spanning the left column width.
- **Spectrum**: keep as a **thin (~48pt) strip** directly under the scrubber — it's a signature feature, Apple Music has none, so keep it subtle. `SpectrumView()` unchanged; just repositioned. (`onAppear`/`onDisappear` tap wiring already correct.)
- **Volume** stays in the top bar (don't duplicate). **Drop `WaveformView`** from Now Playing — the scrubber already covers seeking and it doesn't match Apple Music; keep the file for potential reuse.

## Task 3 — Right column: restyled lyrics + compact Up Next
- **Lyrics**: extract the existing `LyricsView` rendering into the right column and restyle typography to Apple Music — current line large (title2 bold, magenta), previous/next lines medium (body, `textSecondary` with progressive opacity fade for lines further from current), centered text, keep the `ScrollViewReader` auto-scroll-to-center on line change. No data-flow change (still `LyricsService`, still `TimelineView` 0.1s, still `currentLineIndex`). Add a "no lyrics" state that collapses the lyrics area so Up Next can take more room.
- **Up Next** (below lyrics, top-aligned in the same column): a `ScrollView` listing up to 5 items from `playback.queue.upNext` (reuse `QueueService` accessors via `playback.queue`). Each row: small artwork thumb (same `ArtworkSource` helper) + title + artist. Tap → jump that item to current and play (use `QueueService`'s jump API — verify exact method during impl; if none, add a minimal `jump(toIndexInUpNext:)` that promotes the item to current and triggers `loadCurrent`). A trailing "显示完整队列 / Show Full Queue" button calls `onShowQueue()`.
- **Empty Up Next**: hide the section (no placeholder rows).

## Task 4 — Artwork + gradient for YouTube tracks
- `extractGradient` uses the new `artworkImage(for:)` helper so the background gradient derives from YouTube thumbnails too (load thumbnail to `NSImage`, feed `AlbumArtworkExtractor.dominantColors(img, count: 3)`). Cache the resolved `NSImage` in `@State` keyed by track id to avoid re-decoding each frame. Fall back to `[background, surface]` when no art.
- Verify `AlbumArtworkExtractor` handles a 16:9 YouTube thumbnail (it scales to 32×32 and k-means on opaque pixels — fine for any `NSImage`).

## Task 5 — Polish & consistency

- `RootView`: pass `onShowQueue: { showQueue = true }` to `NowPlayingView` in the overlay block.

- `CoverArtModeView`/`VinylModeView` signature change (artworkHash → ArtworkSource) ripples only within `NowPlayingView` — contained.
- YouTube thumbnail → `NSImage` for the gradient is a small `URLSession`/`NSImage(contentsOf: URL)` load; cache by track id to avoid re-decode. Guard against nil (fall back gradient).
- Queue jump API for Up Next tap — verify `QueueService` during impl; add a minimal accessor if missing (no persisted-state change needed beyond what `play()` already records).
- Two-column on very short windows: lyrics column scrolls independently; Up Next scrolls independently. Fine.
