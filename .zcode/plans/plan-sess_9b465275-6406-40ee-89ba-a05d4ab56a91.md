# Muses UI Redesign — Apple Music Style (Phase 9)

## Overview
Transform Muses from its current flat dark UI into an Apple Music-style experience: pure black dark theme, glass sidebar, restructured navigation, dynamic cover art, i18n (en/zh), Metal spectrum rendering, and logo integration.

## Task 1: i18n Infrastructure + Theme Foundation
**Files:** New `App/L10n.swift`, modify `App/RootView.swift` (BrandColors), `Domain/UserPreferences.swift`

**i18n — Swift-based `tr(en, zh)` function (no .strings files needed, works perfectly with SPM):**
```swift
// L10n.swift
import Foundation
enum L10n {
    static var isChinese: Bool {
        Locale.current.language.languageCode?.identifier.hasPrefix("zh") ?? false
    }
}
func tr(_ en: String, _ zh: String) -> String { L10n.isChinese ? zh : en }
```
- Usage: `Text(tr("Home", "首页"))`, `Label(tr("Albums", "专辑"), systemImage: "square.stack")`, `.navigationTitle(tr("Albums", "专辑"))`
- All subsequent tasks use `tr()` for new/modified strings
- Final i18n pass (Task 8) localizes ALL remaining hardcoded strings across 34 feature files

**Theme — BrandColors overhaul:**
- `background` dark: `rgb(0, 0, 0)` (pure black) — was `rgb(0.055, 0.055, 0.07)`
- `surface` dark: `rgb(0.08, 0.08, 0.10)` — slightly above pure black for card backgrounds
- `hairline` → make transparent: `rgb(1, 1, 1, 0)` dark / `rgb(0, 0, 0, 0)` light (effectively removes all dividers without hunting every `Divider()` call)
- Add `static let glassBackground = Color.clear` (materials handle their own appearance)
- Keep magenta/cyan/green/textPrimary/textSecondary unchanged

**PrefKey additions:**
- `PrefKey.gpuAcceleration = "muses.gpuAcceleration"` (Bool, default true)

- Replace single `CIAreaAverage` + shadow/highlight with k-means clustering:

  - Extract all 1024 pixels as RGB

- Keep the same `dominantColors(_:count:)` API signature for backward compat

## Task 7: Metal Spectrum Rendering + GPU Setting
**Files:** New `Features/NowPlaying/MetalSpectrumView.swift`, modify `Features/NowPlaying/SpectrumView.swift`, new `Features/Settings/GPUSettingsView.swift`, modify `Features/Settings/SettingsView.swift`, modify `Features/NowPlaying/NowPlayingView.swift`

**MetalSpectrumView (MTKView via NSViewRepresentable):**
- `NSViewRepresentable` wrapping `MTKView`
- Metal device: `MTLCreateSystemDefaultDevice()`
- Runtime-compiled shaders via `device.makeLibrary(source:options:)`:
  - Vertex shader: renders 64 bar quads (upper + mirrored lower) with gradient
  - Fragment shader: magenta→cyan vertical gradient for upper bars, 30% magenta for mirror
- Uniform buffer: 64 `Float` values (spectrum data) updated per frame
- 60 FPS rendering via `MTKView.preferredFramesPerSecond = 60`
- `@spectrumHandler` callback updates a `CircularBuffer` of Float values (thread-safe)
- Same visual appearance as Canvas-based `SpectrumView` (mirrored bars, gradient, peak decay)

**SpectrumView changes:**
- Add `@AppStorage(PrefKey.gpuAcceleration) var gpuAcceleration = true`
- If `gpuAcceleration`: render `MetalSpectrumView()`; else: existing Canvas rendering
- Both share the same `installSpectrumHandler` / `removeSpectrumHandler` lifecycle

**GPUSettingsView:**

## Risks & Mitigations
- **SwiftData lightweight migration for `pinned: Bool`**: Adding a new property with default value `false` to `@Model` is a no-op migration on macOS 14+. No `VersionedSchema` needed.
- **Metal shader runtime compilation**: `device.makeLibrary(source:options:)` compiles at launch — ~10ms overhead, acceptable. Fallback: if Metal device unavailable (rare on Apple Silicon), fall back to Canvas.
- **`.ultraThinMaterial` on sidebar**: macOS 14 `NavigationSplitView` sidebar may already have system translucency. Using `.containerBackground(.ultraThinMaterial, for: .sidebar)` is the proper API. If it conflicts with system translucency, fall back to `.background(.ultraThinMaterial)` on the VStack.
- **i18n scope (~140 strings across 30 files)**: The `tr(en, zh)` function is mechanical to apply. Most changes are `Text("Foo")` → `Text(tr("Foo", "中文"))`. Estimated 2-3 hours of focused work.
- **AlbumArtworkExtractor k-means**: Simple Lloyd's algorithm on 32x32=1024 pixels with k=4 and 10 iterations is <1ms. No performance concern.

## Key Decisions
- **i18n via `tr(en, zh)` Swift function** — not .strings files. Simplest for SPM, no resource bundling issues, works for 2 languages.
- **Pure black dark theme** — `BrandColors.background` dark = `rgb(0,0,0)`. `hairline` made transparent (removes all dividers globally without touching each call site).
- **Glass via `.ultraThinMaterial`** — SwiftUI native, GPU-accelerated by system, works on macOS 14+.
- **Metal shaders as runtime-compiled string literals** — avoids SPM .metal file complications.
- **Pins as `pinned: Bool` on Album/Playlist** — lightweight SwiftData migration, simple queries.
- **YouTube Music as merged tabbed view** — SegmentedControl with Search/Imports tabs.
- **New page as placeholder** — user will implement recommendation algorithm later.
- **Settings as sheet from profile popover** — not sidebar item, not separate window.
